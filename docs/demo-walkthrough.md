# Demo Walkthrough

> Generated by `scripts/demo.py` against a temporary database. **Synthetic data only.** No external LLM call is made (extractive mode). This tool never assesses causality, recommends treatment or determines reportability.

## 1. Validation rejects an incomplete report

```text
- Batch/lot number is not in the expected format. Use LOT- followed by exactly 5 digits (e.g. LOT-12345).
- Event description is required for a Suspected Adverse Event.
- Event onset date is required for a Suspected Adverse Event.
```

## 2. Two fictional reports are saved

```text
REF-2026-0001  Suspected Adverse Event      LOT-88392  status=New
REF-2026-0002  Product Quality Complaint    LOT-12345  status=New
```

## 3. Status lifecycle with human-in-the-loop closure

```text
New -> In Review: REF-2026-0001 moved to In Review.
Request Closed: Closure requested. REF-2026-0001 stays In Review until a reviewer approves. (pending_approval=True)
Status while frozen: In Review
Reviewer REV-001 decision: REF-2026-0001 approved and Closed.
Final status: Closed
Illegal skip New -> Closed on REF-2026-0002: A New report must go to In Review before it can be Closed.
```
