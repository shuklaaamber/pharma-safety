# SOP-001 Suspected Adverse Event Intake (fictional training document)

Purpose: describe how intake operators record a suspected adverse event report. This SOP covers recording only. Operators do not judge cause, advise on care, or decide regulatory handling.

Mandatory fields: product name, batch/lot number in the format LOT-12345, date received, reporter type, detailed description, event description and event onset date.

Operators must not record patient names, contact details, birth dates or medical history. If a reporter volunteers such details, omit them and record only the event description in neutral words.

Event terms are recorded in the reporter's words and may be mapped to standard terms by a reviewer. For example, "difficulty breathing" may be mapped to the term dyspnea, and "hives" to urticaria. A report describing anaphylaxis is recorded the same way as any other event and is moved to In Review on the same day it is received.

Each saved report receives a unique reference of the form REF-YYYY-XXXX. The reference is quoted in all later communication.
